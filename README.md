# Clinical Ensemble Learning

A supervised machine learning project exploring cardiovascular disease risk prediction using clinical data.

## Objectives

- Investigate dataset quality and unusual values.
- Compare Logistic Regression, Random Forest, and XGBoost.
- Evaluate models using accuracy, precision, recall, F1-score, and ROC-AUC.
- Explore feature importance.
- Build an interactive Streamlit dashboard.

## Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- XGBoost
- Matplotlib and Seaborn
- Streamlit

## Current Progress

- Loaded a cardiovascular disease dataset containing 70,000 records.
- Completed initial data-quality checks on the training split.
- Model training and dashboard development are pending.

## Disclaimer

This is an educational project, not a validated medical diagnostic system. It must not be used to make medical decisions.
